附录 本 港口 基础 设施 一 般 维修 技术 要 求

本 0.1 港口 基础 设施 一 般 维 修 技术 要 求 应 符合 表 本 .0.1 的 规定 。

条 工 0.1 港口 基础 设施 一 般 维 修 技术 要 求
技术 要 求

1. 外 表 及 棱角 出 现 局 部 较 大 损坏 时 ,应 进行 修补 ;
2. 构 件 出 现 结构 性 裂 锋 时 ,应 及 时 检测 、 分 析 原 因 、 采 取 加 园 补 强 措施 ;
3. 表面 出 现 和 剥落、 和 剥离 .钢筋 锈蚀 等 材料 劣化 损坏 时 ,应 安排 定期 检测 和 跟踪 检查 ，

适时 维修

1. 构 件 外 表 及 械 角 出 现 局 部 较 大 损坏 时 ,应 进行 修补 ;
2. 重要 构件 出 现 结构 发 炙 时 ,应 及 时 检测 、 分 析 原 因 、 采 取 加 固 或 补 强 措施 ;
3. 混 闪 土 结构 表面 出 现 材料 劣化 损坏 时 ,应 安排 检测 和 灵 踪 检查 ,适时 进行 维修

1. 构 件 出 现 局 部 变形 和 表面 损坏 时 ,应 进行 矫正 或 修补 ;

2. 焊接 节点 出 现 裂 儿 时 ,应 及 时 修补 ;螺栓 连接 节点 出 现 松动 或 损坏 时 ,应 及 时 紧 固
或 更 换 ;

3. 表 面 应 定期 进行 涂 装 防腐 ,表面 防腐 涂 层 失效 时 应 及 时 除 锈 补 党

1. 混 痊 土 面 层 出 现 大 面积 露 石 、 空 鼓 、 剥 落 等 病害 时 ,应 进行 处 理 ;
2. 源 青 面 层 出 现 泛 油 、 涌 包 、 裂 颖 、 坑 梢 和 车 纹 等 病害 时 ,应 及 时 处 置 ;
畏 砌 面 层 出 现 大 范围 边沿 松散 、 低 溃 沉 陷 或 队 起 时 ,应 及 时 维修

1. 前 沿 水 深 不 满足 设计 及 规范 要 求 时 ,应 及 时 处 理 ;
2. 水 下 障碍 物 和 杂 物 应 及 时 清理

1. 接 上 岸 结 构 出 现 明 显 变形 或 差异 沉降 时 ,应 及 时 进行 检查 分 析 , 并 应 适时 处 理 ;
2. 接 岸 通道 处 出 现 影响 使 用 的 沉降 时 ,应 及 时 处 理 ;

3. 护 面 块 体 和 砸 块 护 面 有 明显 松动 下滑 或 局 部 塌陷 时 ,应 及 时 维修 ;

4.- 高 桂 码 头 下 部 边 坡 冲 刷 或 洪 积 严重 影响 码头 稳定 或 使 用 时 ,应 及 时 处 理

1. 系 船 柱 和 系 船 环 固定 件 缺 损 \ 松 动 时 ,应 及 时 更 换 或 紧 固 ; 柱 体 损坏 或 开裂 时 ,应
及 时 维修 或 更 换 ; 油 漆 防 腐 宜 定期 涂 装 或 补 潜 ;

2. 护航 或 连接 件 损坏 、 脱 落 时 ,应 及 时 更 换 ;

3. 护 轮 坎 磨 损 严重 或 缺损 时 ,应 及 时 维修 ;

4. 系 网 环 缺 失 时 ,应 及 时 修复 ;

.栏杆 基础 松动 .过 大 变形 或 立 杆 缺 损 时 ,应 及 时 修理 ;

6. 铁 咎 梯 捐 坏 影 响 使 用 时 ,应 及 时 更 换 或 修理
