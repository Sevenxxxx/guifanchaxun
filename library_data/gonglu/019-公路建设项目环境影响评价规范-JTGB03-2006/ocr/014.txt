s$.1.3 评价 方法

1 评价 应 分 路 段 进 行 。 应 根据 行政 区 划 \ 自 然 和 社会 环境 特征 以 及 项 目 影响 情况 划
分 路 段 ,在 不 同 路 段 内 选择 代表 性 点 或 代表 性 路 段 进行 分 析 评 价 。

2 应 根据 已 建 的 公路 建设 项 目 社会 环境 影响 的 调查 资料 或 项 目 后 评价 资料 ,进行 类
比分 析 与 评价 。

s$.2 社会 环境 现状 评价

s$.2.1 现状 评价 内 和 容

通过 收集 和 分 析 社 会 经 济 统计 资料 ,对 社会 与 经 济 环境 进行 评价 ,一 般 应 包括 以 下 内 容 :
居民 生活 质量 及 生计 方式 ;
基础 设施 总 体 水 平 ;

主要 工业 门类 及 其 发 展 状况 ;
土地 利用 现状 及 发 展 规划 ;
农林 牧 副 渔业 发 展 状况 ;

矿产 资源 及 其 开发 情况 ;

重要 旅游 资源 及 旅游 业 发 展 状况 ;
重要 文物 资源 保护 及 开发 状况 ;
交通 运输 业 发 展 状况 。

PP Op ~ 中 OO 中 已 二

S$.2.2 调查 方法
1 对 沿线 社会 环境 评价 宜 采 用 实地 调查 的 方法 。 实 地 调查 可 针对 代表 性 点 或 代表
性 路 段 进行 详细 调查 ,推广 全 线 。
