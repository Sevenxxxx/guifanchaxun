条 文 说 明

季节 性 冰冻 地 区 可 以 采用 两 种 方案 防止 路 基 产 生 冻 胀 :

1 整个 冰冻 线 深 度 内 采用 不 易 冻 胀 的 填料 。

2 容许 冰冻 线 深 达 部 分 易 冻 胀 土 层 内 ,但 这 部 分 土 层 所 产生 的 不 均匀 冻 胀 不 会 使 路
表面 的 不 平整 度 超出 容许 值 。

4.3 妾 层

4.3.1 垫 层 主要 设置 在 温度 和 湿度 状况 不 良 的 路 段 上 ,以 改善 路 面 结构 的 使 用 性 能 。
前 者 出 现在 季节 性 冰冻 地 区 路 面 结构 厚度 小 于 最 小 防冻 厚度 要 求 时 ,设置 防冻 垫 层 可 以
使 路 面 结构 免除 或 减轻 冻 胀 和 翻 浆 病 害 。 在 路 床 土 湿 度 较 大 的 控 方 路 段 上 ,设置 排水 垫
层 可 以 芷 干 路 床 土 , 改 善 路 面 结构 的 支承 条 件 。 为 改善 路 基 支 承 条 件 ( 如 减少 不 均匀 变
形 ) 而 设置 的 其 他 层次 ,属于 路 基 范 畴 。

4.3.3 除 砂 \ 砂 砾 等 颗粒 材料 外 ,在 供应 条 件 许可 时 ， 防 谍 垫 层 还 可 采用 煤 淹 、 矿 酒 等
隔 温 性 材料 。

4.4 基层 和 底 基层

4.4.1 对 水 泥 混凝土 面 层 下 基层 的 首要 要 求 是 抗 冲 刷 能 力 。 不 耐 冲 刷 的 基层 表面 ,在
渗入 水 和 荷载 的 共同 作用 下 ,会 产生 证 刷 、 哪 泥 、 板 底 脱 空 和 错 台 等 病害 ,导致 路 面 不 平
整 ,并 加 速 和 加 剧 面 层 板 的 晰 裂 。

提高 基层 的 刚度 ,有 利于 改善 接 颖 的 传 倚 能 力 。 然 而 ,其 作用 只 能 在 基层 未 受 冲 刷 的
前 提 下 才能 得 到 保证 ;同时 ,其 效果 不 如 在 接 颖 内 设置 传 力 杆 。 此 外 ,提高 基层 刚度 虽然 可
以 增加 路 面 结构 的 弯曲 刚度 ,降低 面 层 板 的 荷载 应 力 ,但 也 会 增加 面 层 板 的 温度 翘 昌 变形
(增加 板 底 脱 空 区 范围 ) 和 疙 曲 应 力 , 对 路 面 结构 产生 不 利 影响 ,并 不 一 定 能 减 薄 面 层 厚 度 。

4.4.2 基层 和 底 基 层 可 以 按 组 成 材料 分 为 无 机 结合 料 类 (包括 贫 混 凝 土 、 碾 压 混 凝
土 \ 水 泥 稳定 碎 石 开 级 配水 泥 稳定 碎 石 和 石灰 粉 煤 灰 稳定 碎 石 等 ) 沥青 结合 料 类 (包括
沥青 混凝土 沥青 稳定 碎 石和 开 级 配 源 青 稳定 碎 石 等 ) 和 粒 料 类 (包括 级 配 碎 石 级 配 砾
石 .未 得 分 碎 石 等 ) 三 大 类 型 。

基层 的 受 冲 刷 程度 与 水 的 渗入、 交通 符 载 作用 的 繁重 程度 和 基层 材料 的 抗 冲刷 能 力
有 关 。 各 类 基层 具有 不 同 的 抗 冲刷 能 力 , 它 取决 于 基层 材料 中 结合 料 的 性 质 和 含量 以 及
细 料 (小 于 0.075mmy) 的 含量 。 对 于 基层 的 抗 冲刷 能 力 ,目前 尚未 有 标准 的 试验 方法 和 定
量 评定 指标 。 一 些 试验 研究 结果 表明 ,最 耐 冲 刷 的 是 贫 混凝土 (水 泥 剂 量 7% 或 8% ) 和
沥青 混凝土 (沥青 含量 6% ) 基层 ,其 次 是 水 泥 稳定 碎 石 (水 泥 剂量 5 和 % ) 基层 ,再 次 是 低 剂
量 水 泥 稳 定 碎 石 (水 泥 剂量 3. 5% ) 和 沥青 稳定 碎 石 ( 尖 青 含量 3% ) 基层 , 较 易 冲刷 的 是
