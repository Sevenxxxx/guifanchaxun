本 导 则 用 词 用 语 说 明

1 本 导 则 执行 严格 程度 的 用 词 ,采用 下 列 写 法 :

1 ) 表 格 很 严格 , 非 这样 做 不 可 的 用 词 ,正面 词 采用 "必须 ” ,反面 词 采用 “严禁 ”;

2) 表示 严格 ,在 正常 情况 下 均 应 这 样 做 的 用 词 ,正面 词 采用 "应 ”反面 词 采用 "不 应 ”
或 “不 得 ”;

3) 表 示人 允许 稍 有 选择 ,在 条 件 许可 时 首先 应 这 样 做 的 用 词 ,正面 词 采 用 " 宜 ” ,反面 词
采用 “不宜 ”;

4) 表 示 有 选择 ,在 一 定 条 件 下 可 以 这 样 做 的 用 词 琛 用 "可 ”。

2 引用 标准 的 用 词 采 用 下 列 写 法 :

1) 在 标准 总 则 中 表述 与 相关 标准 的 关系 时 ,采用 " 除 应 符合 本 导 则 的 规定 外 , 尚 应 符
合 国家 和 行业 现行 有 关 标 准 的 规定 ”。

2) 在 标准 条 文 及 其 他 规定 中 ; 当 引 用 的 标准 为 国家 标准 或 行业 标准 时 ,应 表述 为 “应
符合 ( x x x》( x x x ) 的 有 关 规 定 尽

3) 当 引 用 本 标准 中 的 其 他 规定 时 ,应 表述 为 “应 符合 本 导 则 第 x 章 的 有 关 规 定 "“ 应
符合 本 导 则 第 x. x. x 条 的 有 头 规定 "或 “应 按 本 导 则 第 x. x. x 条 的 有 关 规 定 执行 ”。
