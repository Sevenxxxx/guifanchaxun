公路工程建设项目造价数据标准（JTG/T 3812—2020） 
‐ 2 ‐ 
2 术语 
2.0.1 XML 
指可扩展标记语言（ExtensibleMarkupLanguage），标准通用标记语言的子集，是一
种用于标记电子文件使其具有结构性的可扩展标记语言。 
 
2.0.2 XML 文件 
指用XML 语言标准表述电子数据文件内容的计算机电子文档。 
 
2.0.3 XML Schema 文件 
指符合XML 标准文件格式，用一套预先规定的XML 元素和属性创建的用于描述XML
文件格式与数据类型的文件。一个符合本标准的XML 文档必须符合本标准的XML Schema
文件所规定的校验规则。 
 
2.0.4 造价电子数据文件 
指依据本标准规定的数据格式生成的公路造价依据和造价成果的电子数据文件，分
造价依据数据文件和造价成果数据文件两类。造价依据数据文件包含定额资源、费率标
准库、要素费用项目（清单）表库、车船税费库、价格信息、人工单价、规费费率、利
润率、税率数据；造价成果数据文件包含项目建议书估算、可行性研究估算、设计概算、
施工图预算、清单预算、工程决算数据。
