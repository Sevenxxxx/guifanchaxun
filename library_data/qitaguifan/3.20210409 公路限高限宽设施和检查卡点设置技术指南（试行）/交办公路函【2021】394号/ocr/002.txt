公路 限 高 限 宽 设 施 和 检查 卡 点
设置 技术 指南 (试行 )

为 规范 公路 限 高 限 宽 设 施 和 检查 卡 点 设置 ,保障 公路 网 络 畅
通 ,特制 定 本 技术 指南 (以 下 简称 指南 ) 。

一 、 制 定 依据

依据 (中 华人 民 共 和 国 公路 法 交 公 路 安全 保护 条 例 } 竺 法律 法
规 规定 ,交通 运输 部 公安 部 生态 环境 部 住房 城乡 建设 部 关于 深
入 开展 道路 限 高 限 帘 设 施 和 检查 卡 点 专项 整治 行动 的 通知 》( 交 公
路 函 [20201813 号 )( 以 下 简称 (通知 汶 等 有 关 要 求 ,以 及 公路 现行
相关 标准 规范 要 求 。

二 、 适 用 范围

(一 ) 在 全 国 现 有 公路 ( 含 国 、 省 县、 乡 \ 村 道 ) 上 新 增 的 限 高 限
帘 设 施 和 检查 卡 点 ,应 遵守 本 指南 相关 规定 。

(二 ) 在 公路 设计 阶段 设计 的 限 高 限 宽 设 施 和 检查 卡 点 ,应 遵
守 本 指南 相关 技术 规定 ,纳入 公路 基本 建设 程序 管理 ,严格 落实
“三 同时 "制度 。

(三 ) 根 据 ( 通 知 } 要 求 ,依法 保留 但 不 特 合 本 指南 规定 的 公路 限 高
限 宽 设 施 和 检查 卡 点 ,应 接 照 本 指南 相关 要 求 , 进 一 步 完善 和 规范 。
